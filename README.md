# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with vanilla JavaScript, HTML, and CSS.

## How to Play

Click Rock, Paper, or Scissors to make your move. First to 5 wins takes the game.

## What I Built

- DOM manipulation to handle button clicks and display results
- Event delegation — one listener on the parent div instead of three separate ones
- Game state tracked with score variables across rounds
- Win condition logic that removes the event listener when the game ends

## Technologies

HTML | CSS | JavaScript
